# Real-Time Face Detection

A simple, fast, and lightweight real-time face detection application built with Python and OpenCV.

This project uses the YuNet ONNX model, which is highly optimized for real-time performance and runs smoothly on standard CPUs without requiring a heavy GPU.

## 🚀 Features
- Real-time face detection via webcam.
- Uses OpenCV's built-in DNN module.
- Lightweight and fast inference.
- Draws bounding boxes around detected faces.

## 🛠️ Prerequisites
- Python 3.8 or higher
- OpenCV

## 📦 Installation & Usage

1. Clone this repository: [Click here to download the code](https://github.com/mohammad-poursafari/Face-Recognition.git)

2. Install the required dependencies:
   pip install opencv-python

3. Run the application:
   python app.py

## 📝 Usage
Once the webcam window opens, the system will automatically detect faces and draw a green bounding box around them. Press q to quit the application.
